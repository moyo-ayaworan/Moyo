# Website screenshot sources

Captured 10 November 2026 from the 0.4.18 renderer, using an isolated browser fixture and existing website sample photographs. No customer project was opened or changed.

- app-setup.webp: existing current 0.4.18 book-size UI capture.
- app-folders.webp: folder browser, sample project.
- app-ai.webp: AI overview, sample project with illustrative analysis state.
- app-editor.webp: current book canvas and tools, sample project.
- app-review.webp: review workflow, sample project.

These images demonstrate the interface, not measured AI accuracy, analysis speed or live account/payment functionality. Sample photo dimensions were read before automatic layout to preserve their proportions. Captures are converted to WebP without UI retouching. The AI fixture does not constitute a completed real analysis run.

Website uses precompressed WebP directly to avoid redundant image transformations. Hero is preloaded; walkthrough images are lazy loaded. Each walkthrough image links to its full-resolution asset. Desktop 1440px and mobile 390px browser checks confirmed all five images decode and no horizontal overflow. TypeScript check passes.
